## Corrections to prior claims

- OLD SHARED POLICY SCOPE — prameyallc.github.io/edu-app-privacy scopes itself to apps with no accounts, no uploads, and no health or financial data, and (per the portfolio pattern) implies no networking. OmniBuild fits the 'no accounts / no uploads / no health data' part, but the no-networking implication is FALSE. TRUTH: OmniBuild makes an outbound HTTPS connection to huggingface.co to download AI model weights when the user starts the download in Settings. It carries a public model repo name plus the IP address and headers any request reveals; it carries no user content.
- README.md line 23 states OmniBuild is 'Fully on-device — questions never leave your iPhone'. The second half is TRUE; the first half over-claims. TRUTH: questions and logs never leave the device, and inference is fully on-device — but the app is not fully offline. It downloads model weights from Hugging Face over HTTPS on first use. The accurate formulation is 'your content never leaves your device; the model file is downloaded once from Hugging Face'.
- Info.plist NSHealthShareUsageDescription claims OmniBuild 'optionally accesses HealthKit (steps, sleep, activity) with your explicit permission to provide educational correlations and insights'. FALSE. TRUTH: there is zero HealthKit code in the repo. The app cannot access HealthKit, has never asked for it, and shows no permission prompt. The string describes a feature that does not exist.
